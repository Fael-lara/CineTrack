# CineTrack

O CineTrack é um gerenciador pessoal de filmes desenvolvido na disciplina de Programação de Sistemas Web.

Na Parte 1, a aplicação funciona inteiramente no navegador, utilizando HTML, CSS e JavaScript puro. Os dados são armazenados localmente no navegador por meio do `localStorage`.

## Funcionalidades

- Listagem de filmes em cards
- Busca por título
- Filtro por status
- Cadastro de filmes
- Edição de filmes
- Remoção de filmes
- Avaliação em estrelas
- Persistência dos dados com `localStorage`
- Layout responsivo
- Tema claro e escuro

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
