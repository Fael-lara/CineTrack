# CineTrack

O CineTrack é um gerenciador pessoal de filmes desenvolvido na disciplina de Programação de Sistemas Web.
A aplicação permitirá cadastrar, listar, buscar, editar e remover filmes.
Cada filme terá informações como título, ano, gênero, pôster, status, nota e comentário.
O projeto será desenvolvido em etapas, começando pelo frontend interativo e evoluindo posteriormente para uma aplicação full stack.
